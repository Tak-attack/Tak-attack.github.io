7 WONDERS

世界の七不思議得 点 計 算

項目ごとに、全プレイヤー分を順番に入力していく方式です。軍事→財宝→七不思議→…と上から進めるだけで、カテゴリ別の内訳と順位を自動で計算します。基本ゲームに加え、拡張「指導者（リーダーズ）」と「都市（シティーズ）」に対応しています。

使う拡張

プレイヤー

各プレイヤーのボード（七不思議）を選んでください。拡張のボード（ROMA／ABU SIMBEL／PETRA／BYZANTIUM）も一覧に表示されますが、対応する拡張を有効にしないと選べません。プレイヤー名は任意で、入れなくてもボード名で表示されます。

得点入力（項目ごと）

各項目で、全員分を順番に入力してから次の項目へ進んでください。

順位

    同点の場合は、コイン（財宝）の枚数が多いプレイヤーが上位になります（公式タイブレーク）。

    結果をレシート幅の用紙風プレビューで確認してから、レシートプリンター（RP-F10など）で印刷できます。iPadでは「PDFで保存」で結果を80mm幅のPDFに書き出し、共有シートから「ファイルに保存」や SII URL Print Agent などの印刷アプリに渡して RP-F10 で印刷できます。

    結果をテキストでシェア

    順位とカテゴリ別の内訳をテキストにまとめました。コピーしてLINEやSNSなどに貼り付けたり、ファイルとして保存できます。

    「世界の七不思議（7 Wonders）」基本ゲームと拡張「指導者（リーダーズ）」「都市（シティーズ）」の得点計算用ページです。その他の拡張（「大海戦」など）のカテゴリには対応していません。

    印刷プレビュー

    レシートの内容を確認してください。「このレシートを印刷」を押すと印刷ダイアログが開くので、レシートプリンター（RP-F10）を選んで印刷してください。Androidでは SII Print Service 経由で RP-F10 に印刷されます。iPadでは「PDFで保存」を押すと80mm幅のPDFを共有シートで書き出せるので、「ファイルに保存」や SII URL Print Agent などの印刷アプリから RP-F10 に印刷してください。
