7 WONDERS

世界の七不思議得 点 計 算

項目ごとに、全プレイヤー分を順番に入力していく方式です。七不思議→財産→軍事紛争→…と上から進めるだけで、カテゴリ別の内訳と順位を自動で計算します。基本ゲームに加え、拡張「指導者（リーダーズ）」と「都市（シティーズ）」に対応しています。

表示モード
「1項目ずつ」は項目ごとに1ページ表示します。前へ／次へボタンと横スワイプで移動できます。

使う拡張
チーム戦は都市（シティーズ）拡張をONにすると選べます。ONにすると、各プレイヤーの「相方」を選んでペアの合計点でチーム順位を出せます。

プレイヤー

各プレイヤーのボード（七不思議）を選んでください。

詳しい説明

拡張のボード（ROMA／ABU SIMBEL／PETRA／BYZANTIUM）も一覧に表示されますが、対応する拡張を有効にしないと選べません。ボードの面はA面／B面を切り替えられます（初期はA面で、選んだ面は結果や印刷にも「RHODOS（☀A面）」「RHODOS（☾B面）」のように、単色の太陽／月のマークと一緒に表示されます）。プレイヤーは2〜7人で、都市（シティーズ）をONにすると8人まで追加できます（追加／削除ボタンは上限・下限で止まります）。プレイヤー名は任意で、16文字まで入力できます。表示名は、ボードと名前の両方がある場合は「ボード名（☀A面）（名前）」、ボードだけの場合は「ボード名（☀A面）」、名前だけの場合は名前、どちらも無い場合は「（ボード未選択）」と表示されます。「入力をクリア」は、そのプレイヤーの得点入力だけをゼロに戻します（ボード・名前・面・相方は残りますが、財産・市民の入力モードは初期値に戻ります）。

得点入力（項目ごと）

各項目で、全員分を順番に入力してから次の項目へ進んでください。

      レシート幅

      結果はレシート幅の用紙風プレビューで確認してから印刷できます。レシート幅は58mm／80mmを切り替えられます。

      詳しい説明

      結果をレシート幅の用紙風プレビューで確認してから、対応プリンターで印刷できます。レシート幅は58mm／80mmを切り替えられ、選んだ幅はこの端末に保存されます。「PDFで保存」は結果を選択中の幅のPDFファイルとして直接ダウンロードします。「PDFを共有」は共有シートを開きます（iPadでは「ファイルに保存」や SII URL Print Agent などの印刷アプリに渡して対応プリンターで印刷できます）。ファイル共有に対応していない環境では、「PDFを共有」を押すとPDFをダウンロードします。「結果を画像で保存／共有」は順位結果をPNG画像として書き出します（ファイル共有に対応した環境では共有シートを開き、非対応環境ではダウンロードします）。

      「レシートプリンターで印刷（URL Print Agent）」は、SII URL Print Agent アプリが入った端末で、ブラウザ（Safari／Chrome）からこのページを開いたときに使えます。アプリ内ブラウザでは起動しない場合があります。また、生成されるPDFのサイズが上限（Androidは約150KB、iOSは約500KB）を超える場合は、印刷は実行されません。

      結果をテキストでシェア

      順位とカテゴリ別の内訳をテキストにまとめました。コピーしてLINEやSNSなどに貼り付けたり、ファイルとして保存できます。テキスト自体は上の「結果発表」を押すまで表示されません。

      次のゲーム用に、得点入力だけを全員ゼロに戻します（プレイヤー・ボード・名前・拡張・チーム設定はそのまま残ります）。財産・市民の入力モードも初期値（財産は「枚数で入力」、市民は「カード枚数」）に戻ります。

      名前・ボード・拡張も含めすべて初期状態に戻します（プレイヤーは3人、ボードは未選択、名前は空、拡張・チーム戦はOFFに戻ります）。テーマとレシート幅の設定は残ります。

      「世界の七不思議（7 Wonders）」基本ゲームと拡張「指導者（リーダーズ）」「都市（シティーズ）」の得点計算用ページです。その他の拡張（「大海戦」など）のカテゴリには対応していません。

      印刷プレビュー

      印刷の内容を確認してください。問題なければ「この記録を印刷」から印刷できます。

      詳しい説明

      印刷の内容を確認してください。「この記録を印刷」を押すと印刷ダイアログが開くので、プリンターを選んで印刷してください。iOSでは「PDFを共有」を押すと選択中の幅のPDFを共有シートで書き出せるので、「ファイルに保存」や印刷アプリから対応プリンターで印刷してください（ファイル共有に対応していない環境では、押すとPDFをダウンロードします）。「PDFで保存」はPDFファイルを直接ダウンロードします。SII URL Print Agent アプリが入った端末では「レシートプリンターで印刷」から直接印刷もできます。
