- 世界の七不思議 得点計算アプリ（7Wonder Score App）

https://tak-attack.github.io/7-wonder-score-app/

世界の七不思議（第二版、指導者拡張、都市拡張）対応の得点計算アプリです。第一版でも適応できるはず。

科学（緑）の自動計算といった定番の機能から、市民建造物（青）の枚数だけボタンを押すと合計できる機能など、計算しやすさにこだわりました。

- ボードゲーム専用電卓（Boardgame Score Calc）

https://tak-attack.github.io/boardgame-score-calc/

ボードゲームの得点計算のために設計した電卓＋得点表アプリ。
A calculator + score sheet app designed for board game scoring.

<img width="30%" height="30%" alt="Screenshot_20261125-161009" src="https://github.com/user-attachments/assets/df597995-a211-4a9f-a439-1df56446b48f" />

特徴

-最大8人×20項目の得点表。名前・項目はタップで編集でき、プレイヤーの並び替えもできる
-計算式を見ながら入力できるテンキー（四則演算・括弧・x²、配列の切替と高さ調整つき）
-クイックモード：タップで加点、長押しで2桁入力、アンドゥは最大100手
-マイナス項目とタイブレーク項目に対応（タイブレークを得点に含める併用タイプも）。タイブレークの値は括弧で表示
-合計1位に王冠マーク（同点はタイブレークで判定）。各項目のトップの値には下線
-小数は切り捨てで表示・計算
-ゲーム別プリセット、自作プリセットの保存
-結果の履歴保存（最大200件）。検索・並べ替えと、保存時の未入力チェックつき
-テーマ4種、表の文字サイズ4段階、横画面の2カラム入力、入力中は画面を消さない設定
-PCではキーボード操作にも対応
-PWA対応でホーム画面に追加でき、オフラインでも使える
-データはブラウザ内に保存されるので、アカウント登録は不要
-レシート印刷（SII URL Print Agent対応機種）とPDF保存／共有、テキスト出力
-結果をカラー画像で共有（設定中のテーマの色を反映）
