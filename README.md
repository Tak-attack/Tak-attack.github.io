# Tak-attack.github.io

成果物置き場
- 世界の七不思議 得点計算アプリ（7Wonder Score App）

https://tak-attack.github.io/7-wonder-score-app/

世界の七不思議（第二版、指導者拡張、都市拡張）対応の得点計算アプリです。第一版でも適応できるはず。

科学（緑）の自動計算といった定番の機能から、市民建造物（青）の枚数だけボタンを押すと合計できる機能など、計算しやすさにこだわりました。

英語対応、指導者＆都市以外の拡張は要望があれば追加します。

- ボードゲーム専用電卓（Boardgame Score Calc）

https://tak-attack.github.io/boardgame-score-calc/

ボードゲームの得点計算のために設計した電卓＋得点表アプリ。
A calculator + score sheet app designed for board game scoring.

特徴 / Features

- プレイヤー×項目の得点表で、計算式を見ながら入力できる / Spreadsheet-style score table (players × categories) with always-visible formulas
- 四則演算と括弧に対応したテンキー / Keypad with +, −, ×, ÷ and parentheses
- クイックモード：タップでそのまま加点、長押しで2桁入力 / Quick mode — tap to add points, long-press for two-digit entry
- マイナス項目とタイブレーク項目に対応 / Negative categories and tiebreak categories
- 小数は切り捨てで表示・計算 / Decimals are truncated in display and totals
- 合計1位に王冠マーク / A crown marks the leading player
- ゲーム別プリセット（外部ファイルから読み込み、オフライン時は内蔵プリセットを使用） / Per-game presets loaded from an external file, with built-in presets available offline
- 自分用のプリセット保存と、結果の履歴保存（最大200件） / Save your own presets and score history (up to 200 entries)
- レシート印刷（58mm／80mm切替）とPDF保存に対応 / Receipt printing (58mm / 80mm widths) and PDF export
- テーマ4種類とフルスクリーン表示に対応 / Four color themes and fullscreen mode
- データはブラウザ内に保存されるので、アカウント登録は不要 / Data is stored locally in your browser — no account needed

英語対応、得点表のプリセット登録希望は要望があれば対応します。
プリセット登録希望は**得点用紙が必要なアプリのみ**対応いたします。
